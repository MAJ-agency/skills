# Sources

Documents bruts fournis en entrée du projet (cadrage, présentations, notes client, exports de systèmes amont, specs tierces).

**Ce dossier n'est pas de la spécification.** Rien ici ne fait autorité tant qu'une règle n'a pas été extraite, questionnée (grilling) et écrite dans la documentation validée. En cas de contradiction entre deux sources, la contradiction est une **question ouverte**, pas un arbitrage à faire seul.

Convention de nommage : `<sujet>-<AAAA-MM-JJ>.<ext>` — la date est celle du document, pas celle de son dépôt ici.

Ce dossier est **explicitement exclu** de la nomenclature `<TRI>-<N>-<slug>.md` ([`../methode/nomenclature.md`](../methode/nomenclature.md)) : un trigramme désigne un sujet **du projet**, or une source est une entrée externe dont le sujet n'a pas encore été tranché. Un document ne reçoit d'identifiant qu'une fois devenu du contenu de ce dépôt.
