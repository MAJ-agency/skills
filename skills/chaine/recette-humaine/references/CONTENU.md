# Ce que contient le skill recette-humaine, et pourquoi

Aucun script : la recette est l'étape de jugement, elle ne s'automatise pas. Le skill fixe le déroulé en quatre phases et l'arrêt obligatoire après l'inventaire ; `methode.md` fixe le vocabulaire (neuf familles de défauts, deux grilles d'exploration) et le gabarit de l'inventaire.

Ce qui vient du projet : les règles du chemin, le glossaire, le registre de règles `docs/metier/regles/`, le catalogue de rôles et les schémas partagés (`packages/contracts` dans le socle), les emplacements de tests de `.claude/rules/tests.md`, la convention `tickets` pour la spec de défauts.
