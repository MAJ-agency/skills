## Questions à l'architecte

1. **Le relais dans le dépôt de la CLI (n° 4) : un texte, ou un changement du relais ?** Le relais pourrait accepter un chemin de CLI (une variable) ou essayer `pnpm --filter @maj-agency/anchorpost exec anchorpost` quand le binaire manque ; c'est une décision de conception que les tickets n'ont pas. **Recommandation : le texte de la retouche maintenant** (Anchorpost est le seul dépôt dans ce cas, et son `anchorpost.mjs` est déjà adapté de la même façon) ; un ticket de suite si un second dépôt le demande.

4. **Le ticket de suite d'`A-200` point 3** : y mettre la règle 14 du gate avec `double-relecture.mjs` (n° 12). **Recommandation : oui**, les deux lisent `Prouve:` ensemble ou aucun.
